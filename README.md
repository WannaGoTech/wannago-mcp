Votre Description**) en un écosystème complet de production :

   - Conservation intacte de votre logo maître ou synthèse vectorielle automatique (`logoPath: "auto"`).
   - Alignement mathématique sous-pixel : `Largeur Ligne 2 == Largeur Ligne 1` à `0.001pt`.
   - Icônes d'application **Squircle 1024x1024** (`22.37%` de rayon continu, `>10%` de marge optique), `favicon.ico` multi-couches et **Studio 3D interactif** (`1.022` échelle).

## Guide d'Intégration Pas-à-Pas (Installation en 2 Minutes)

### Prérequis Système
- **Node.js** `>= 20`
- **Python** `>= 3.10` avec `pymupdf`, `Pillow`, `numpy` :
  ```bash
  pip install pymupdf Pillow numpy
  ```
- **FFmpeg** installé sur le système (pour le rendu de la vidéo 20s `Promo.mp4`).

### Étape 1 : Cloner le Plugin WannaGo
```bash
git clone https://github.com/WannaGoTech/wannago-mcp.git
cd wannago-mcp
npm install --omit=dev
```

### Étape 2 : Connecter à votre Agent IA

#### A. Intégration dans **Google Antigravity**
Option 1 (Plugin natif) :
```bash
# Windows (PowerShell)
Copy-Item -Recurse . "$HOME\.gemini\config\plugins\wannago"

# macOS / Linux
cp -R . ~/.gemini/config/plugins/wannago
```
Option 2 (Fichier `~/.gemini/config/mcp_config.json`) :
```json
{
  "mcpServers": {
    "wannago-mcp": {
      "command": "node",
      "args": ["/chemin/absolu/vers/wannago-mcp/dist/index.js"],
      "env": {
        "WANNAGO_API_KEY": "wgo_trial_VOTRE_CLE_RECUE_PAR_EMAIL"
      }
    }
  }
}
```

#### B. Intégration dans **Claude Desktop / Claude Code**
```bash
claude mcp add wannago-mcp -e WANNAGO_API_KEY=wgo_trial_VOTRE_CLE -- node /chemin/absolu/vers/wannago-mcp/dist/index.js
```

#### C. Intégration dans **Cursor / Windsurf / VS Code**
Ajoutez dans `.cursor/mcp.json` ou `.vscode/mcp.json` :
```json
{
  "mcpServers": {
    "wannago-mcp": {
      "command": "node",
      "args": ["/chemin/absolu/vers/wannago-mcp/dist/index.js"],
      "env": {
        "WANNAGO_API_KEY": "wgo_trial_VOTRE_CLE_RECUE_PAR_EMAIL"

```

## Security Architecture, Permission Boundaries & MCP Tool Safety Annotations

To guarantee enterprise safety and full transparency for AI agents and MCP registries (such as **MCP.Pub**, **Official MCP Registry**, **Glama**, and **Smithery**), **WannaGo MCP v3.1** enforces 5 strict security boundaries:

| Security Control | Implementation & Default Behavior | Affected Tools |
| :--- | :--- | :--- |
| **1. Zero-Invention Human-in-the-Loop Gatekeeper** | The agent is **forbidden from inventing** brand inspirations, colors, contacts, or posts. It must call `wannago_interactive_discovery` and wait for explicit user confirmation in chat before generating or publishing. | `wannago_interactive_discovery`, `acp_launch_brand_one_shot` |
| **2. Read-Only & Scoped Workspace Generation (22 Tools)** | Read-only inspection tools (`acp_get_status`, `wannago_audit_design`, `wannago_audit_visual_and_post`, `wannago_detect_peak_hours`, `social_list_platforms`, `social_check_auth`, `social_get_analytics`, `social_read_inbox`, `social_search_posts`, `social_get_trends`) have **zero external write side-effects** (`readOnlyHint: true`). File generators write strictly inside the user-specified `outputDir`. | All Audit, Analytics, Discovery & Brand Kit tools |
| **3. Mandatory Dry-Run Preview Before Publishing (`dryRun: true`)** | Social publishing tools support `dryRun: true` to populate the composer and capture a local verification screenshot **without clicking Publish**. Live publication requires explicit user approval in chat. | `social_publish_post`, `social_reply_to_post`, `social_send_dm` |
| **4. Single-Site Collaborator Isolation (Zero Shared Credentials)** | No third-party credentials are bundled. When deploying to WordPress/Pressable, `wannago_pressable_collaborator_isolation` scopes the user's `collaboratorEmail` **strictly to their single dedicated site** (`otherWannaGoTechSitesVisible: false`, `masterAccountListingBlocked: true`). | `wannago_pressable_collaborator_isolation`, `wannago_wordpress_pressable_deploy` |
| **5. Strict Opt-In Hardware Bridge (Android ADB)** | Android ADB tools (`wannago_phone_*`) are **100% opt-in (`socialAccountMode: "skip"` by default)** and only execute when a user physically connects their own device via USB debugging and explicitly requests mobile automation. | `wannago_phone_status`, `wannago_phone_read_otp`, `wannago_phone_artemis_task` |
