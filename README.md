## Architecture & Proposition de Valeur (FR)

**WannaGo MCP** (`wannago-mcp`) est un serveur **Model Context Protocol (MCP)** et **Agent Control Protocol (ACP)** à 7 portes déterministes. Il permet à votre agent IA (**Google Antigravity**, **Claude Desktop**, **Claude Code**, **Cursor**, **Windsurf**) de transformer **2 entrées simples** dans le chat (**1. Votre Logo** + **2. Votre Description**) en un écosystème complet de production :

1. **Suite Logo Vectorielle & Lockups à Largeur Mathématiquement Égale (`01_Logos/`, `02_Logo_3D_and_Animations/`, `03_Favicons_and_App_Icons/`)**
   - Conservation intacte de votre logo maître ou synthèse vectorielle automatique (`logoPath: "auto"`).
   - Alignement mathématique sous-pixel : `Largeur Ligne 2 == Largeur Ligne 1` à `0.001pt`.
   - Icônes d'application **Squircle 1024x1024** (`22.37%` de rayon continu, `>10%` de marge optique), `favicon.ico` multi-couches et **Studio 3D interactif** (`1.022` échelle).
2. **Palette Certifiée WCAG 2.1 AA/AAA, Nuancier Adobe `.ASE`, Papeterie Print A4 & Signatures Outlook 600px (`04_Headers/`, `05_Email_Signatures/`, `07_Brand_Colors/`)**
   - Calcul de luminance relative et synthèse automatique d'un token d'encre profonde accessible (`>= 5.0:1` sur fond clair).
   - Fichier binaire **Adobe Swatch Exchange (`.ase`)** pour Illustrator, Photoshop et InDesign.
   - En-têtes de lettres A4 vectoriels, bannières réseaux sociaux ajustées sans coupure de texte et signatures email `600px` (`tabular-nums`, isolation BiDi RTL).
3. **Sites Web de Production Multilingues (`FR, EN, DE, AR`), Brand Hubs & Chartes PDF HD (`09_Commercial_Presentations_A4/`, `11_Production_Website/`)**
   - Génération du contrat `DESIGN.md` + **4 Sites Web de Production** (6 anatomies de sections distinctes, grille Bento avec cellule dominante 2x2, 8 états interactifs, support natif RTL Arabe).
   - **4 Brand Hubs HTML5**, **4 Manuels de Charte Graphique PDF HD** et **4 Présentations Commerciales A4**.
4. **Vidéo de Lancement 20 Secondes (`Promo.mp4` + Miniature `Promo.jpg` en Frame 0 + `share-copy.txt`)**
   - Vidéo `1920x1080` (16:9) ou `1080x1920` (9:16) à 30fps synchronisée sur les temps forts musicaux + effets sonores + miniature `Promo.jpg` incrustée directement en **Frame 0** pour un affichage immédiat sur X, LinkedIn, Slack et Discord.

## Guide d'Intégration Pas-à-Pas (Installation en 2 Minutes)

### Prérequis Système
- **Node.js** `>= 20`
- **Python** `>= 3.10` avec `pymupdf`, `Pillow`, `numpy` :
  ```bash
  pip install pymupdf Pillow numpy
  ```
- **FFmpeg** installé sur le système (pour le rendu de la vidéo 20s `Promo.mp4`).

### Étape 1 : Cloner le Plugin WannaGo
```bash
git clone https://github.com/WannaGoTech/wannago-mcp.git
cd wannago-mcp
npm install --omit=dev
```

### Étape 2 : Connecter à votre Agent IA

#### A. Intégration dans **Google Antigravity**
Option 1 (Plugin natif) :
```bash
# Windows (PowerShell)
Copy-Item -Recurse . "$HOME\.gemini\config\plugins\wannago"

# macOS / Linux
cp -R . ~/.gemini/config/plugins/wannago
```
Option 2 (Fichier `~/.gemini/config/mcp_config.json`) :
```json
{
  "mcpServers": {
    "wannago-mcp": {
      "command": "node",
      "args": ["/chemin/absolu/vers/wannago-mcp/dist/index.js"],
      "env": {
        "WANNAGO_API_KEY": "wgo_trial_VOTRE_CLE_RECUE_PAR_EMAIL"
      }
    }
  }
}
```

#### B. Intégration dans **Claude Desktop / Claude Code**
```bash
claude mcp add wannago-mcp -e WANNAGO_API_KEY=wgo_trial_VOTRE_CLE -- node /chemin/absolu/vers/wannago-mcp/dist/index.js
```

#### C. Intégration dans **Cursor / Windsurf / VS Code**
Ajoutez dans `.cursor/mcp.json` ou `.vscode/mcp.json` :
```json
{
  "mcpServers": {
    "wannago-mcp": {
      "command": "node",
      "args": ["/chemin/absolu/vers/wannago-mcp/dist/index.js"],
      "env": {
        "WANNAGO_API_KEY": "wgo_trial_VOTRE_CLE_RECUE_PAR_EMAIL"
      }
    }
  }
}
```

## Liste Complète des 26 Outils MCP Exposés

### 1. Licence, ACP, Identité de Marque, Sites Web (WordPress/Pressable), Everything-API & Vidéo Promo 20s
- `wannago_verify_license` : Vérifie ou active en session une clé `wgo_trial_...` (3 jours) ou `wgo_live_...`.
- `acp_launch_brand_one_shot` : Exécute les 7 Portes ACP en une seule commande à partir du Logo + Description (ou Lien Site Web).
- `acp_get_status` : Retourne l'état exact des 7 Portes ACP et la prochaine instruction déterministe pour l'agent.
- `wannago_generate_brand_kit` : Génère les 12 dossiers du Brand Kit + 4 Sites Web + Thème WordPress + Everything-API + Vidéo 20s (`Promo.mp4`) + Audit `100/100`.
- `wannago_generate_social_profile_packs` : Génère les Bios calibrées (FR/EN/DE/AR), Descriptions longues, Photos de profil `800x800` et Bannières de couverture aux dimensions exactes des 9 plateformes.
- `wannago_url_to_everything_api` : Embarque `https://github.com/edsadr/everything-api` dans le projet (`12_Everything_API/`) et transforme tout lien de site web fourni par l'utilisateur en API REST JSON + OpenAPI 3.1.
- `wannago_wordpress_pressable_deploy` : Génère le thème bloc WordPress certifié et orchestre le déploiement via `wordpress-studio` MCP ou `pressable` MCP (Partenaire Officiel Automattic — support site web gratuit à `contact@wannago.tech`).

- `wannago_audit_design` : Exécute le scanner statique de qualité WannaGo (`0 anomalie`) sur n'importe quel dossier.
